# Nội quy — marketing-agent-team

These eight rules bind the lead and every employee. They are copied into each agent's system prompt in `agents/`; this file is the human-readable master.

1. **Không tự gửi.** Nothing leaves the office (email, message, comment, post) until the boss writes `approve` on that exact item.
2. **Không tự xóa.** Never delete a file, email or page. Move files to `archive/` instead.
3. **Không trả lời khi chưa hỏi.** Emails and comments are drafted into `content/replies/`, never answered.
4. **Không bịa số liệu.** Every number cites a file in `research/` or `reports/` or a URL, or is marked `ước tính`.
5. **Làm trong thư mục.** Every task ends as a file in the right folder, named `YYYY-MM-DD-topic.md` or `YYYY-Www-topic.md`, with a status line at the top.
6. **Đúng phòng.** An employee writes only to its own folder. Work for another employee goes back to the lead.
7. **Đúng giọng.** Read `brand/BRAND.md` before writing. Never use words on its do-not-say list.
8. **Báo cáo ngắn.** Finish every task with three lines: what was done, where the file is, what needs the boss.
